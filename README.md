# Вулкан Маркетинг

Первая тестовая версия главной страницы на **Astro 7.4.2**, без React и внешних UI-библиотек. Основа — выбранный рендер «Контрастная пауза»: светлая редакционная типографика, три услуги, тёмный кейс, преимущества, этапы, отзывы, обращение.

## Запуск у себя

Откройте эту папку в VS Code. Для этой версии требуется Node.js 22.23.4+; Node.js 24 подходит. Нужная версия указана также в `package.json`.

В терминале в корне проекта:

```bash
npm ci
npm run dev
```

Откройте адрес, который покажет Astro, обычно `http://localhost:4321/`. Терминал оставьте работающим. Изменения в исходниках появятся в браузере после сохранения. Остановка — `Ctrl+C`.

Если PowerShell снова блокирует `npm.ps1`, используйте те же команды через `npm.cmd`: например, `npm.cmd ci` и `npm.cmd run dev`. Менять политику выполнения для этого не требуется.

## Где менять содержимое

| Файл | Назначение |
| --- | --- |
| `src/data/site.ts` | Название, метаданные, услуги, цены, кейсы, преимущества, этапы и места для отзывов |
| `src/pages/index.astro` | Структура главной страницы и подключение разделов |
| `src/components/Hero.astro` | Первый экран: заголовок, вулканчик, задачи отдела и мобильная композиция |
| `src/assets/volcano-mascot.png` | Согласованный персонаж агентства на прозрачном фоне |
| `src/styles/global.css` | Цвета, типографика, мобильная версия, светлая и тёмная темы |
| `src/layouts/BaseLayout.astro` | Общий HTML, метатеги, canonical и JSON-LD |
| `src/components/ProjectMockup.astro` | Демонстрационные превью проектов |
| `public/images/logo.jpg` | Переданный вами логотип |
| `src/scripts/site.ts` | Карусели, меню, тема и диалоги |

Три услуги сохранены по выбранному рендеру: «Стратегия», «Реклама», «Аналитика». Цены — **тестовые**, не согласованные тарифы. Кейсы — учебные сценарии без выдуманных достигнутых результатов. Вместо вымышленных отзывов стоят явные заготовки. Блог пока не добавлен: по обсуждению сначала согласуем главную.

## Что уже работает

- Светлая и тёмная темы, запоминание выбора в текущем браузере.
- Мобильное меню с закрытием по ссылке, клику снаружи и Escape.
- Две независимые карусели без автопрокрутки: кнопки, стрелки клавиатуры и свайп.
- Диалоги с описанием услуг и тестовая форма с проверкой обязательных полей.
- Основное содержание и все слайды находятся в статическом HTML. При выключенном JS слайды показываются последовательно.
- Форма **не отправляет и не сохраняет данные**. Для реального приёма обращений нужно согласовать канал и подключить обработчик.

## Проверка сборки

```bash
npm run build
npm run verify
npm run preview
```

`dist/` — готовые файлы для статического хостинга. `preview` показывает именно собранную версию; откройте адрес из терминала. `verify` проверяет HTML тестовой версии: ссылки, локальные ресурсы, JSON-LD, наличие содержимого, синтаксис скриптов и запрет индексации. Это не замена визуальной проверке в браузере.

## Публикация на вашем хостинге

1. Сохраните резервную копию работающего сайта.
2. Соберите проект: `npm run build`.
3. Просмотрите его через `npm run preview`.
4. Загрузите **содержимое** `dist/` в согласованную папку сайта. `node_modules`, `src` и исходный `package.json` статическому хостингу не нужны.
5. Настройте на хостинге HTTPS и ответ HTTP 404 для `404.html`; проверьте главную и несуществующий адрес.

Конкретный хостинг и его пути из соседнего чата недоступны, поэтому они здесь не выдуманы. Если рабочий сайт уже существует, тестовую сборку сначала разместите на отдельном тестовом адресе.

## SEO и AI-поиск

Подробности и ссылки на официальные источники — в `docs/SEO.md`. Это свежая базовая реализация, а не подтверждение всех договорённостей из соседнего чата: получить его полную историю не удалось.

Сейчас включён `noindex`, а карта сайта не содержит тестовых URL. Подготовка к индексации: заменить демо-содержание, указать реальный домен в `.env` (`SITE_URL`), изменить `demoMode` на `false` в `src/data/site.ts` и выставить `SITE_INDEXABLE=true`, затем пересобрать. Не открывайте для индексации вымышленные данные и черновые цены.

В корне также есть служебный манифест для размещённого предпросмотра; на вашем статическом хостинге он не нужен.
