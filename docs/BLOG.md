# Блог «Вулкан Маркетинг»

## Структура
- `/blog/` — архив статей и анонсов.
- `/blog/<slug>/` — отдельная страница материала.
- На главной автоматически выводятся три последних материала.
- Общая шапка и подвал для всех страниц.
- Полные статьи хранятся в `src/content/blog/`. Данные анонсов и порядок материалов задаёт `src/data/articles.ts`.

## Статус текущего наполнения
Полные статьи импортированы из материалов автора. Отдельные анонсы в `articles.ts` имеют `status: 'preview'` и закрыты от поисковой индексации.

## Как загрузить полноценную статью
1. Получить оригинальные текст, фотографии, дату и прямую ссылку на статью.
2. Положить изображения в `public/images/blog/<slug>/`.
3. После сверки с оригиналом записать текст в `src/content/blog/<slug>.md` с полями `title`, `excerpt`, `publishedAt` (строка `YYYY-MM-DD`), `images` и `originalUrl` для конкретной публикации в Дзене.
4. Поставить обложку в `images[0]` и указать её размеры в `coverWidth` и `coverHeight`. Поле `coverCaption` задаёт подпись обложки на странице статьи.
5. Вставить остальные иллюстрации в исходном порядке с помощью `<figure>`, `<img>` и `<figcaption>`. Если обложка встречается в середине текста, указать `coverInBody: true` и оставить её там.
6. Привязать внутренние ссылки к маршрутам `/blog/<slug>/`. Запустить `npm.cmd run build`, затем `npm.cmd run verify` и визуально проверить страницы.

## Поисковая индексация
- Отдельный URL, title, description и canonical для каждой статьи.
- Первая фотография используется для Open Graph и Twitter Card.
- Для опубликованных статей предусмотрена разметка `BlogPosting`.
- Страницы `preview` всегда получают `noindex` и исключаются из sitemap.
- При запуске доступность индексации зависит от `site.demoMode` и `SITE_INDEXABLE`.
- В деморежиме `site.demoMode = true` весь сайт остаётся `noindex`.

## Конфиденциальность
Блог статический: без форм сбора данных, рекламных счётчиков и автоматического копирования из Дзена.
Материалы размещаются вручную и хранятся в исходниках сайта.

## Замечания
Если у анонса отсутствует обложка, его карточка показывает заглушку.
