# Блог «Вулкан Маркетинг»

## Структура
- `/blog/` — архив статей и анонсов.
- `/blog/<slug>/` — отдельная страница материала.
- На главной автоматически выводятся три последних материала.
- Общая шапка и подвал для всех страниц.
- Источник данных статей: `src/data/articles.ts`.

## Статус текущего наполнения
Дзен не позволил получить оригиналы текстов и фотографий автоматически.
Первые три записи в `articles.ts` — только **анонсы** на основе открытых сообщений автора в Telegram.
Они имеют `status: 'preview'` и не выдаются за полные статьи.
Все анонсы закрыты от поисковой индексации.

## Как загрузить полноценную статью
1. Получить оригинальные текст, фотографии, дату и прямую ссылку на статью.
2. Положить изображения в `public/images/blog/<slug>/`.
3. Заполнить запись в `src/data/articles.ts`: `title`, `excerpt`, `publishedAt`, `images`, `sections`, `originalUrl`.
4. **Первую фотографию** поставить в `images[0]`, например `/images/blog/<slug>/01.webp`.
   Эта фотография автоматически станет обложкой на главной странице, в архиве и в самой статье.
5. Тело статьи записать в `sections`, например:
   `sections: [{ heading: 'Заголовок', paragraphs: ['Абзац один', 'Абзац два'], images: ['/images/blog/<slug>/02.webp'] }]`.
   Дополнительные изображения могут находиться внутри секций. Первую фотографию не нужно дублировать.
6. Установить `status: 'published'` только после сверки текста и фотографий с оригиналом.
7. Для `originalUrl` использовать URL **конкретной** публикации в Дзене, не только канала.
8. Запустить `npm.cmd run build`, затем `npm.cmd run verify` и визуально проверить через `npm.cmd run dev`.

## Поисковая индексация
- Отдельный URL, title, description и canonical для каждой статьи.
- Первая фотография используется для Open Graph и Twitter Card.
- Для опубликованных статей предусмотрена разметка `BlogPosting`.
- Страницы `preview` всегда получают `noindex` и исключаются из sitemap.
- При запуске доступность индексации зависит от `site.demoMode` и `SITE_INDEXABLE`.
- В деморежиме `site.demoMode = true` весь сайт остаётся `noindex`.

## Конфиденциальность
Блог статический: без форм сбора данных, рекламных счётчиков и автоматического копирования из Дзена.
Материалы размещаются вручную и хранятся в исходниках сайта.

## Замечания
Пока обложки отсутствуют, карточки показывают явно обозначенные заглушки.
Не заменяйте их чужими фотографиями без подтверждения прав и соответствия статье.
Заголовки двух анонсов редакционно сформулированы по темам из Telegram; перед публикацией полных материалов их нужно сверить с точными заголовками на Дзене.
